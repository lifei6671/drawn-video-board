# 白纸铅笔职场讽喻风

本次提交包含用户确认的个人画风预设及其默认主图。`library.json` 使用现有自定义预设格式，无需修改加载器或手动导入即可按名称选择。

![默认主图](assets/02441c55971fbde2b0538838f896085d7b16b5e0556ebd6ad903d1fbd6ad4ece.png)

## 画风规则

- 近白微暖纸底，石墨铅笔轮廓与轻微复描，使用斜排线和少量交叉排线形成灰度。
- 圆头、细长四肢的成人职场小人，头发默认仅两三根轻短线。
- 表情平静克制，不默认添加汗滴、惊讶线或夸张喜剧表情。
- 人物简化，日常道具保留可信透视与适量素描细节，背景开阔留白。
- 黑白灰为主，少量低饱和淡粉点缀。人物关系、场景和构图按当前内容重新设计。

主图由内置 image_gen 生成，并根据用户反馈减少头发、收敛表情后获得确认。它同时用作预设预览与生图参考，不固定后续分镜中的人物身份、递交文件动作或构图。

## 使用

在 Skill 根目录使用已配置的 Python 环境：

```text
python -m cs_board_video style list
python -m cs_board_video style set --project <项目路径> --preset "白纸铅笔职场讽喻风"
```

选择前遵循项目既有分镜审核流程；选择后会复制配方、主图和画布底色，仍需完成当前项目的画风审核。

`assets/39f3112c6232f94af45ad19a7169a98570481529a2fb579e01d6f5693287e3dd.png` 是现有默认绘制手模板的原字节副本，用于满足自定义预设的资源契约。它不改变主图的铅笔画风，也不表示参考样片采用画笔绘制动画。

个人预设目录继续默认忽略。本次仅显式提交此预设索引和它实际引用的两张图片，不包含原视频抽帧、本机路径、生成日志或其他个人预设资料。
